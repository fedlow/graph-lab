# Лабораторная работа: Графы

## Цель
Научиться работать с ориентированными графами, BFS, матрицей и списком смежности.

## Файлы проекта
- `directed_graph.py` — класс `DirectedGraph`.
- `bfs.py` — обход в ширину.
- `adjacency_matrix.py` — граф в виде матрицы смежности.
- `adjacency_list.py` — граф в виде списка смежности.
- `demo.py` — демонстрация.

## 1. DirectedGraph

Ориентированный граф хранит:
- `vertices` — множество вершин;
- `adj` — словарь {вершина: [соседи]}.

Методы:
- `add_vertex(v)` — добавляет вершину без рёбер;
- `add_edge(u, v)` — добавляет ориентированное ребро **u → v** (не наоборот);
- `neighbors(v)` — возвращает список соседей.

## 2. BFS

Обход в ширину с использованием `collections.deque`:
- стартуем с заданной вершины;
- помечаем вершины посещёнными при добавлении в очередь;
- проходим по всем соседям в порядке добавления.

Сложность — **O(V + E)**.

## 3. Матрица смежности

Класс `AdjacencyMatrixGraph` хранит:
- `vertices` — список вершин;
- `index` — {вершина: её индекс};
- `matrix` — двумерный список 0/1.

Функция `build_matrix_from_edges(edges)` строит граф из списка рёбер.

Плюсы: проверка ребра — O(1), простота.
Минусы: память O(V²), невыгодно для разреженных графов.

## 4. Список смежности

Класс `AdjacencyListGraph` хранит словарь {вершина: [соседи]}.

Функция `build_list_from_edges(edges)` строит граф из списка рёбер.

Плюсы: память O(V + E), обход графа быстрее.
Минусы: проверка ребра — O(deg(v)).

## Сравнение представлений

| Свойство | Матрица | Список |
|---|---|---|
| Память | O(V²) | O(V + E) |
| Проверка ребра | O(1) | O(deg) |
| Перебор соседей | O(V) | O(deg) |
| Хорошо для | плотных графов | разреженных графов |

## Вывод

Ориентированный граф удобно хранить в виде списка смежности — особенно
для разреженных графов. BFS обходит граф по уровням и работает за O(V + E).
Матрица смежности даёт быструю проверку ребра, но тратит O(V²) памяти.
